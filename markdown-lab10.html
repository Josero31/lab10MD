Introducción

El presente laboratorio aplica técnicas de aprendizaje semi-supervisado sobre el dataset Adult Income (UCI Machine Learning Repository). El objetivo es comparar modelos supervisados puros contra algoritmos semi-supervisados bajo un escenario donde solo una fracción pequeña de los datos de entrenamiento posee etiqueta.

El dataset fue recolectado a partir del Censo de los Estados Unidos de 1994 y contiene información socioeconómica de individuos. La variable objetivo indica si el ingreso anual de una persona supera o no los USD 50,000.

Selección y Descripción del Dataset

Fuente: UCI Machine Learning Repository — Adult Income Dataset URL: https://archive.ics.uci.edu/dataset/2/adult Dimensiones: 48,842 filas × 15 columnas Variable objetivo: income — binaria (<=50K / >50K)

El dataset cumple con los requisitos mínimos del laboratorio: más de 1,000 filas, más de 8 columnas, fuente pública y confiable, y tarea de clasificación binaria apta para el escenario semi-supervisado.

Diseño del Escenario Semi-Supervisado

set.seed(42)

# Separar test (20% del total, siempre etiquetado)
test_idx  <- sample(seq_len(nrow(df_clean)), size = 0.2 * nrow(df_clean))
test_set  <- df_clean[test_idx, ]
train_all <- df_clean[-test_idx, ]

# De los datos de entrenamiento, etiquetar solo el 10%
label_frac  <- 0.10
labeled_idx <- sample(seq_len(nrow(train_all)),
                      size = label_frac * nrow(train_all))

labeled_set   <- train_all[labeled_idx, ]
unlabeled_set <- train_all[-labeled_idx, ]
unlabeled_set$income <- NA

cat("=== Partición del dataset ===\n")
## === Partición del dataset ===
cat("Conjunto etiquetado   :", nrow(labeled_set),
    "(", round(nrow(labeled_set)/nrow(df_clean)*100, 1), "% del total)\n")
## Conjunto etiquetado   : 3617 ( 8 % del total)
cat("Conjunto no etiquetado:", nrow(unlabeled_set),
    "(", round(nrow(unlabeled_set)/nrow(df_clean)*100, 1), "% del total)\n")
## Conjunto no etiquetado: 32561 ( 72 % del total)
cat("Conjunto de prueba    :", nrow(test_set),
    "(", round(nrow(test_set)/nrow(df_clean)*100, 1), "% del total)\n")
## Conjunto de prueba    : 9044 ( 20 % del total)
particion_df <- data.frame(
  conjunto   = c("Etiquetado\n(train)", "No etiquetado\n(train)", "Prueba\n(test)"),
  n          = c(nrow(labeled_set), nrow(unlabeled_set), nrow(test_set)),
  tipo       = c("Etiquetado", "No etiquetado", "Test")
)

ggplot(particion_df, aes(x = reorder(conjunto, n), y = n, fill = tipo)) +
  geom_col(width = 0.55, show.legend = FALSE) +
  geom_text(aes(label = scales::comma(n)), hjust = -0.1, size = 4) +
  coord_flip() +
  scale_fill_manual(values = c("#1b9e77", "#7570b3", "#d95f02")) +
  scale_y_continuous(labels = scales::comma, expand = expansion(mult = c(0, 0.15))) +
  labs(title = "Distribución de los conjuntos de datos",
       subtitle = "Escenario semi-supervisado (10% etiquetado)",
       x = NULL, y = "Número de observaciones") +
  theme_minimal()

La partición simula un escenario realista donde el etiquetado manual es costoso. Solo el 10% del conjunto de entrenamiento posee etiqueta conocida (~3,617 muestras), mientras que el 90% restante (~32,561 muestras) se tratará como no etiquetado en los algoritmos semi-supervisados. El conjunto de prueba (9,044 muestras) permanece completamente etiquetado para evaluación objetiva.
